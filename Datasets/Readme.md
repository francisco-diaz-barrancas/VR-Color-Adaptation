# 📊 Dataset Description

This repository includes the **final processed dataset** used in the analysis of the VR experiment on color constancy and chromatic adaptation.

The dataset has been derived from raw data generated by the Unity application and subsequently refined to retain only the variables relevant for analysis.

---

## 🔄 Data Pipeline Overview

### 1. Raw Data Generation (Unity Application)

The Unity-based VR system automatically records experimental data during runtime, including:

* Lighting conditions
* Exposure time
* User selections
* Full spatial configuration of patches

These raw logs contain detailed information required for experiment tracking but are not directly suitable for statistical analysis.

---

### 2. Data Cleaning and Processing

A preprocessing pipeline was applied to transform the raw logs into a structured dataset.

This process includes:

* Removal of incomplete or invalid trials
* Filtering of inconsistent selections
* Selection of relevant variables
* Simplification of spatial information
* Standardization of naming conventions

The result is a **clean and compact dataset focused on perceptual performance analysis**.

---

## 📁 Final Dataset

The processed dataset is provided in:

```text
Dataset/vr_chromatic_adaptation_datasets.csv
```

---

## 📋 Variables (Processed Dataset)

The final dataset contains the following variables:

| Variable                | Description                                        | Type        |
| ----------------------- | -------------------------------------------------- | ----------- |
| participant_id          | Unique identifier for each participant (e.g., P01) | Categorical |
| participant_number      | Numeric participant index                          | Numerical   |
| illuminant              | Illumination condition (D65, Red, Green, Blue)     | Categorical |
| time_seconds            | Exposure time in seconds                           | Numerical   |
| trial_within_illuminant | Trial index within each illumination condition     | Numerical   |
| selected_chip           | Color patch selected by the participant            | Categorical |
| correct                 | Correct selection (1) / incorrect (0)              | Binary      |
| selection_valid         | Valid trial indicator (1 = valid, 0 = invalid)     | Binary      |

---

## 🧪 Data Collection Context

* Data was collected in a controlled Virtual Reality environment
* Participants performed perceptual tasks under varying illumination conditions
* Each row represents a single observation within a trial

---

## 🔐 Anonymization

All participant data has been anonymized to ensure privacy and compliance with ethical standards.

---

## 🔬 Reproducibility

The dataset can be reproduced by:

1. Running the Unity application included in this repository
2. Executing the experiment under the same conditions
3. Collecting raw output logs
4. Applying the described preprocessing pipeline

---

## ⚠️ Notes

* This dataset corresponds to the **processed version**, not raw logs
* Spatial configuration variables have been removed during preprocessing
* The dataset is optimized for statistical analysis of perceptual responses
* Minor variability may occur depending on hardware and user interaction
